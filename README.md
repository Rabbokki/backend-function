## ✨ 프로젝트 소개
### 🍷 DopamineX - 프리미엄 주류를 한눈에, 간편하게!
>1. **다양한 주류 상품을 한 곳에서 탐색해보세요!**  
   위스키, 와인, 맥주 등 카테고리별로 필터링하여 원하는 술을 쉽게 찾을 수 있어요.
>2. **회원 전용 주류 쇼핑 서비스 제공!**  
   로그인한 사용자만 상품을 담고 결제할 수 있도록 설계된 합법적 주류 거래 시스템입니다.
>3. **간편한 장바구니 및 결제 시스템**  
   복잡한 구매 과정을 최소화하여 몇 번의 클릭만으로 구매가 가능합니다.


## 핵심 기능

### 🛍️ 상품 탐색 & 장바구니

> * 다양한 주류 상품 목록을 카테고리, 가격순, 인기순 등으로 필터링 가능
> * 원하는 상품을 장바구니에 담고, 수량 조절 및 삭제 기능 제공

### 💳 결제 시스템

> * 장바구니에 담긴 상품을 한 번에 결제할 수 있는 간편한 결제 기능
> * 결제 내역은 마이페이지 > 주문 내역에서 확인 가능


### 🔔 채팅

> * 사용자 간 또는 관리자와의 1:1 채팅 시스템
> * 추후 고객센터 자동 응답 기능으로 확장 가능

### 🗨️ 상품 리뷰 & 별점

> * 구매 후, 해당 상품에 대한 리뷰 및 별점 작성 가능
> * 다른 사용자들의 리뷰를 보고 합리적인 구매 판단 가능


### 🧑🏻 마이페이지

> *  회원 정보 수정, 주문 내역 조회, 내 리뷰 관리
